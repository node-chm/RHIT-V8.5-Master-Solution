# สารบัญเอกสาร SOP โครงการ RHIT V9.0 (`sop/`)

โฟลเดอร์นี้ใช้เป็นศูนย์กลางจัดเก็บเอกสารวิธีปฏิบัติมาตรฐาน (Standard Operating Procedures: SOP) ของโครงการ **RHIT V9.0** (`suchartorr/RHIT-V8.5-Master-Solution`) เพื่อให้ผู้ร่วมงานและ AI ผู้ช่วยอ้างอิงกติกาและขั้นตอนการทำงานได้ตรงกัน และรองรับการเพิ่มหรือปรับปรุงไฟล์ SOP ในอนาคตอย่างเป็นระบบ

## วัตถุประสงค์ของโฟลเดอร์ `sop/`
- รวมเอกสาร SOP ของโครงการให้อยู่ในหมวดหมู่เดียว แยกชัดเจนจากไฟล์งานวิจัย โค้ด และไฟล์ข้อมูลหลัก
- กำหนดจุดอ้างอิงกลางที่สอดคล้องกันระหว่างเอกสาร SOP, `AI_RESEARCH_SKILL.md` และประเด็นติดตามงาน (Issue / Pull Request)
- รองรับการอัปโหลดไฟล์ SOP เรื่องใหม่ๆ หรือการแก้ไขตามวงจรการทำงาน โดยไม่กระทบตัวเลขหรือกติกาหลักของ SSoT โดยไม่ได้รับการตรวจสอบและอนุมัติ

## รายการเอกสาร SOP ในโฟลเดอร์นี้
- **`sop_github_suchartorr_node_chm_v9_0.md`** — SOP ต้นเรื่องว่าด้วยกติกาและขั้นตอนการทำงานร่วมกันบน GitHub ระหว่างผู้ดูแลหลัก (`suchartorr`) และผู้ปฏิบัติงาน (`node` / `node-chm`) รวมถึงรูปแบบการตั้งชื่อ Branch แบบที่ 3 (`ws<เลข>/<ผู้ทำ>-<เรื่อง>`) และการส่ง Pull Request เข้า `suchartorr:main` โดยตรง

## กติกาการเพิ่มและแก้ไขไฟล์ใน `sop/`
1. **การตั้งชื่อไฟล์:** ใช้ตัวพิมพ์เล็กและเครื่องหมายขีดล่าง (`_`) คั่นคำให้สื่อความหมายชัดเจนและไม่ซ้ำกับไฟล์เดิม
2. **การอัปโหลดและปรับแก้:** ดำเนินการบน Branch งานที่แยกเฉพาะเรื่อง (เช่น `ws1/node-ai-skill-sop`) และบันทึกที่มา/ทางเลือก/ผลการทดลองไว้ใน Issue ที่เกี่ยวข้อง
3. **การนำขึ้นระบบหลัก:** ซิงก์อัปเดตล่าสุดจาก `suchartorr:main` เข้า Branch ของผู้ทำ แล้วเปิด Pull Request เข้า `suchartorr:main` โดยตรงเพื่อให้ `suchartorr` ตรวจสอบและอัปเดต
